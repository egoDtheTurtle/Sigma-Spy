# Sigma Spy

Self-contained recovery build of Sigma Spy.

`Main.lua` includes the runtime modules, templates, ReGui library, and parser. It does not fetch Sigma Spy, ReGui, or parser code from the network at runtime.

Run `Main.lua` directly in a compatible Roblox executor. The custom font is optional; the default code font is used when it is unavailable.

The `src` tree contains the editable source. `Main.lua` is the bundled release file.
